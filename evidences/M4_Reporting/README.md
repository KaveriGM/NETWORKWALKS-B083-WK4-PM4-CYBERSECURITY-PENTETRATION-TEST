# Mediroza Hospital – Public Evidence Package

This folder contains sanitized evidence screenshots from the authorized Mediroza Hospital penetration-testing assessment.

## Organization

- M1_Initial_Access – Footprinting and authentication testing evidence
- M2_Data_Extraction – Document-protection and password-recovery evidence
- M3_Critical_Data_Exposure – Directory and historical database exposure evidence
- M4_Reporting – Evidence index and handling notes

## Redaction Notice

Sensitive patient, staff, shareholder, password, and medical information has been redacted from the public evidence package. The redactions are intentional and should remain in place before publishing to a public repository.

## Intended Use

This evidence package is intended for an authorized security-assessment portfolio or project repository. Do not use the evidence against systems without explicit authorization.
